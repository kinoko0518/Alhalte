Alhalte ポータブル版
=====================

■ 起動
1. フォルダを書き込み可能な場所に展開する（Program Files などは避ける）。
2. フォルダ内の `alhalte-cafe`（Windows では `alhalte-cafe.exe`）を起動する。
3. ブラウザが http://127.0.0.1:8080/ を開く。
4. 最初は好きなアカウント名とパスワード（8文字以上）でサインインする。
   初めての名前は、その場で新しいアカウントとして登録される。
   名前はログイン ID になる。パスワードは Argon2id で保存される。

■ データとバックアップ
- データはこのフォルダの `data/` に保存される。
  - `data/maitre-d-local.sqlite3` : ローカルアカウント / セッション / 部屋一覧
  - `data/cellar/` : 部屋ログ・素材の実体
- バックアップはフォルダごとコピーする（`data/` を含める）。
- 部屋状態は 60 秒ごとに cellar へ保存される。終了直前の最大約 60 秒は
  失われることがある。正確に残したい場合は、部屋の ZIP export を使う。

■ LAN（スマホ・他 PC から）
- 同じ Wi-Fi / Ethernet の端末から `http://<このPCのIP>:8080/` を開く。
- 初回は Windows ファイアウォールの確認が出る。「プライベート ネットワーク」を
  許可する。許可しないと LAN から接続できない。
- cellar (8081) と banquette は loopback のみで、LAN には公開されない。

■ 停止
- コンソールで Ctrl+C を押す。
- コンソールを閉じた場合、`alhalte-*.exe` が残ることがある。
  その場合はタスク マネージャーで終了する。
- 自動再起動・ファイルログ・OS のサービス登録はない。

■ 注意
- HTTP であり、ログインパスワードは LAN 上を平文で流れる。
  信頼できる学内 LAN だけで使い、インターネットには公開しないこと。
- Windows SmartScreen が出た場合は「詳細情報」→「実行」。
- ポート 8080 / 8081 が使用中の場合は `Restaurant.toml` を編集する。
  UI と API は同じ `maitre-d.port` で配信される。
- パスワードを忘れた場合は、そのアカウントを復旧する UI はない。
  `data/maitre-d-local.sqlite3` を消すと全ローカルアカウント・部屋一覧が
  消える（cellar の実体は残るが、部屋一覧から開けなくなる）。
